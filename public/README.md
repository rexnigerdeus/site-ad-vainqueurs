# Dossier public/

Placez ici les fichiers statiques servis à la racine du site :

- `logo.png` — logo officiel du Temple des Vainqueurs (transparent, ≥ 512×512 px)
- `logo-white.png` — version sur fond sombre (pour header/footer)
- `favicon.ico` — icône navigateur (32×32 ou multi-size)
- `og.png` — image Open Graph (1200×630 px) pour partage réseaux sociaux
- `apple-touch-icon.png` — 180×180 px

Une fois le logo déposé, il sera automatiquement utilisé par le Header, le Footer et les métadonnées SEO (préfixé par `/`).
